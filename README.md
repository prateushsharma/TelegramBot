# Photo to PDF Telegram Bot

A customizable Python Telegram bot that collects multiple photos from a user and converts them into a single PDF.

## Current flow

1. User sends `/start`.
2. Bot shows **📸 Photo to PDF**.
3. User sends one or more photos.
4. Bot keeps the photos in order.
5. User presses **✅ Convert N photos**.
6. Bot asks for a PDF filename.
7. User enters the filename.
8. Bot shows **📄 Create PDF**.
9. Bot creates the PDF and sends it back.
10. Temporary files are deleted after conversion.

The project is intentionally structured so more tools/buttons can be added later.

## Requirements

- Python 3.10+
- Telegram bot token from [@BotFather](https://t.me/BotFather)

## Setup on Ubuntu

```bash
git clone YOUR_REPOSITORY_URL
cd photo-to-pdf-telegram-bot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env
```

Put your Telegram token in `.env`:

```env
TELEGRAM_BOT_TOKEN=123456789:YOUR_REAL_TOKEN
MAX_PHOTOS=30
```

Run:

```bash
python bot.py
```

Open Telegram, find your bot, and send:

```text
/start
```

## Stop the bot

Press:

```text
Ctrl+C
```

## Security

Never commit your `.env` file or Telegram token.

`.env` is already included in `.gitignore`.

If you accidentally publish a Telegram token, revoke it immediately using BotFather and generate a new one.

## Adding more buttons later

The main menu is generated by `main_menu()` in `bot.py`.

Add another button there, then add a callback handler and its corresponding function/state.

## Notes

Telegram sends several resolutions for an uploaded photo. The bot downloads the largest available photo version.

For image documents sent as files rather than Telegram "photos", support can be added later.
